### Added

- On a Mac, an agent can read the location of this Mac, the Apple Weather forecast, file names in Desktop, Documents, and Downloads, the running apps, text in a chat image, and whether Focus is on. You can refuse each reading. A value that enters the chat can go to the model provider.
